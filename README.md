# NGA-West2 Flatfile Explorer

This repository organizes the public NGA-West2 flatfile Excel workbooks into reproducible SQLite and RDS data products, then provides a Shiny app for browsing earthquakes, stations, records, ground-motion values, and summary statistics.

Traditional Chinese documentation is available in [README.zh-TW.md](README.zh-TW.md).

## Contents

```text
data/        Original NGA-West2 public flatfile Excel workbooks
docs/        Development plan, data processing notes, SQLite/RDS usage docs, source report
manifests/   Input and validation manifests generated by the scripts
scripts/     Reproducible data inspection, build, and validation scripts
shiny-app/   Shiny dashboard for interactive exploration
```

Generated outputs are intentionally ignored by Git:

```text
output/sqlite/nga_west2.sqlite
output/rds/
shiny-app/data/cache/
```

## Source Data

The repository includes:

- 11 RotD50 damping flatfiles from 0.5% to 30%.
- 1 vertical 5% damping flatfile.
- The NGA-West2 database report: `docs/webpeer-2013-03-timothy_d._ancheta_robert_b._darragh_jonathan_p._stewart_emel_seyhan.pdf`.

The processing plan follows the report's four-table metadata model:

- earthquake source table
- site database
- propagation path table
- record catalog

The public flatfiles are merged summaries of these tables. The SQLite database built here is therefore an application-oriented normalized database reconstructed from the public release files, not an official internal PEER database dump.

## Build Data Products

From the repository root:

```bash
Rscript scripts/inspect_nga_west2_inputs.R
Rscript scripts/build_nga_west2_sqlite.R
Rscript scripts/build_nga_west2_rds.R
Rscript scripts/validate_nga_west2_outputs.R
```

The SQLite builder also has a Python wrapper:

```bash
python3 scripts/build_nga_west2_sqlite.py
```

## Run the Shiny App

After building the SQLite database and cache files:

```bash
Rscript -e 'shiny::runApp("shiny-app", host = "127.0.0.1", port = 3838, launch.browser = FALSE)'
```

Then open:

```text
http://127.0.0.1:3838
```

The app includes:

- Overview counts and summary charts.
- Interactive epicenter and station maps.
- Server-side table previews.
- Basic statistical charts.
- Lazy-loaded RDS analysis for selected wide flatfiles.

## Notes

- Official missing-value codes such as `-999` are preserved.
- Response spectra are stored as JSON arrays in SQLite to avoid a very large long-format spectra table.
- `event_region_derived` and `station_region_derived` are browsing aids derived from event names and broad station coordinate boxes. They are not official metadata.
- Taiwan station coordinates are separated from the broad China coordinate rule in the derived station region field.
